# Vienna Urban Astronomy Project: Sky-Watcher GoTo Setup

## Project Overview

Initiating a Vienna-based urban astronomy project using a Sky-Watcher GoTo telescope optimized for light-polluted city conditions. The project focuses on digital imaging with USB cameras rather than traditional eyepiece observation, making astronomy accessible in urban environments like Friedensbrücke.

## Technical Setup

### Hardware Configuration
- **Telescope**: Sky-Watcher 6" f/8 Newtonian reflector
- **Mount**: AZ-GTi GoTo alt-azimuth mount with SynScan controller
- **Camera**: USB eyepiece camera (ZWO ASI224MC or similar)
- **Location**: Roof-mounted installation for optimal sky access

### Software Ecosystem
- **INDI Server**: Universal astronomy device control framework
- **KStars**: Telescope control, observation planning, and image capture
- **SharpCap**: Real-time image capture and processing
- **PHD2**: Autoguiding for stable long-exposure imaging

## Urban Astronomy Challenges & Solutions

### Light Pollution Mitigation
- **Digital imaging** provides better contrast than visual observation
- **Narrowband filters** enhance faint object visibility
- **Short exposure techniques** optimized for bright skies
- **Target selection** focused on bright objects (Moon, planets, bright clusters)

### Practical Implementation
- **Robotic operation** minimizes manual intervention
- **Remote control** via INDI web interface
- **Automated scheduling** for optimal observation times
- **Weather protection** with automated parking in poor conditions
