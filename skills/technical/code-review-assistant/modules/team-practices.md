# Team Practices

**Confidence**: 🟡 Medium  
**Last validated**: 2025-11-08  
**Primary sources**: Accelerate 2024 (DevEx chapter), GitLab Handbook Code Review Process (2025 update), Atlassian Team Playbook (2025), LinearB Engineering Benchmarks (2024)

---

## 1. Policy & Guidelines

- Maintain a living “Definition of Review Done” covering scope, testing, docs, and sign-off requirements.  
- Keep coding standards and architectural guidelines accessible; link from PR templates.  
- For critical domains, require dual reviewer sign-off or SME involvement.  
- Document “What we don’t review manually” (formatting, lint issues) to push to automation.

---

## 2. Reviewer Rotation & Load Balancing

- Use weekly rotations or auto-assign tools to distribute work fairly.  
- Set max concurrent reviews per engineer (e.g., 5) to avoid burnout.  
- Encourage pair reviews or mob sessions for complex changes.  
- Track review debt; escalate if backlog exceeds SLA.

---

## 3. Onboarding & Mentorship

- Pair new reviewers with experienced mentors for first 5–10 reviews.  
- Provide cheat sheets, past exemplary reviews, and example comments.  
- Conduct monthly lunch-and-learn sessions on review anti-patterns and success stories.

---

## 4. Continuous Improvement

- Review metrics monthly: turnaround, rework, defect escape rate.  
- Run “review retros” to inspect random merged PRs and calibrate standards.  
- Collect anonymous feedback from authors on review quality; address friction quickly.  
- Celebrate high-quality reviews—recognition reinforces desired behaviours.

---

## 5. Remote & Async Collaboration

- Encourage video/synchronous reviews for contentious changes.  
- Use comment threading; resolve when consensus achieved.  
- Summarize synchronous discussions in PR for traceability.  
- Provide timezone overlap guidelines to keep flow-of-work moving.

---

### Checklist
- [ ] Definition of Review Done documented and visible.  
- [ ] Review rotation or assignment automation active.  
- [ ] Metrics dashboard reviewed monthly with action items.  
- [ ] Onboarding materials up to date and assigned mentor per newcomer.  
- [ ] Feedback loop (survey/slack bot) collecting author satisfaction.

Healthy review culture accelerates delivery, improves quality, and keeps teams engaged.*** End Patch
