# Summary

Google’s **2026-04-21** post *Deep Research Max: a step change for autonomous research agents* is the **current** public narrative (supersedes older December-only docs for capability claims).

## What changed

- **Two agents:** **Deep Research** (lower latency, interactive) and **Deep Research Max** (deeper, async-style workloads).
- **Model:** Described as built on **Gemini 3.1 Pro**.
- **MCP:** Remote **Model Context Protocol** servers can be combined with web search, uploads, and file stores; optional **web-off** private corpora runs.
- **Product extras:** **Collaborative planning**, **real-time streaming** of intermediate steps, **native charts/infographics** (HTML; **Nano Banana** referenced for visuals).
- **Availability:** **Public preview**, **paid** Gemini API tiers; **Vertex / Google Cloud** for enterprises described as coming soon.
