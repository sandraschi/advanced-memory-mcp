# Features Overview

Advanced Memory MCP provides comprehensive research and knowledge management capabilities, evolved from Basic Memory MCP with expanded research intelligence and improved reliability.

## Research Intelligence

### Multi-Source Research
Advanced Memory MCP aggregates intelligence from multiple specialized sources simultaneously:

- **Web Intelligence**: DuckDuckGo, Google (SerpApi), Bing search with time-based and domain filtering
- **Academic Research**: arXiv preprint database with category-specific searches and citation analysis
- **Code Intelligence**: GitHub repository analysis with code search and implementation pattern discovery
- **Narrative Intelligence**: TV Tropes analysis for character archetypes and storytelling patterns

### Research Pipeline
The research pipeline provides end-to-end intelligence gathering:

1. **Query Processing**: Multi-source query distribution with intelligent routing
2. **Result Aggregation**: Relevance scoring and cross-source synthesis
3. **Quality Assurance**: Source credibility assessment and fact verification
4. **Synthesis**: Unified result presentation with confidence scoring

## Document Intelligence

### Document Processing
Advanced document processing capabilities for research and knowledge management:

- **Format Support**: PDF, EPUB, text files, Markdown documents
- **Content Extraction**: Intelligent text extraction with structure preservation
- **Metadata Analysis**: Document metadata extraction and analysis
- **Chunking Strategies**: Semantic and structural document segmentation

### RAG (Retrieval-Augmented Generation)
Vector-based knowledge retrieval for large document analysis:

- **Embedding Generation**: Sentence Transformers for semantic similarity
- **Vector Storage**: ChromaDB persistent vector database
- **Similarity Search**: Semantic retrieval with configurable thresholds
- **Context Integration**: Primary source integration with direct quotes

## Skill Synthesis

### Research-Driven Skill Creation
Automated expert skill generation from comprehensive research:

- **Multi-Source Integration**: Synthesis across web, academic, and code sources
- **FastMCP Sampling**: Direct LLM interrogation for skill generation
- **Citation Management**: Primary source attribution and reference tracking
- **Quality Validation**: Automated skill validation and enhancement

### Claude Skills Compatibility
Bidirectional conversion between zettelkasten notes and Anthropic's Claude Skills format:

- **Export Functionality**: Transform knowledge base into reusable skills
- **Import Capability**: Integrate community skills into knowledge management
- **Format Preservation**: Maintain metadata and relationships during conversion
- **Platform Compatibility**: Support for claude.ai, Claude API, and community repositories

## Knowledge Management

### Zettelkasten System
Atomic note-based knowledge management system:

- **Note Linking**: Bidirectional relationships between concepts
- **Metadata Management**: Frontmatter-based note classification
- **Project Isolation**: Multi-project support with data separation
- **Search Capabilities**: Full-text search with filtering and pagination

### Content Management
Comprehensive content manipulation tools:

- **CRUD Operations**: Create, read, update, delete notes with full metadata support
- **Bulk Operations**: Batch processing for large knowledge base management
- **Version Control**: Git-based change tracking and history management
- **Export Flexibility**: Multiple format support (PDF, HTML, Markdown, etc.)

## Platform Architecture

### MCP Implementation
Model Context Protocol server with enhanced reliability:

- **FastMCP Framework**: High-performance MCP server implementation
- **Portmanteau Tools**: Consolidated tool interface for compatibility
- **Error Handling**: Comprehensive error recovery and logging

### Cross-Platform Compatibility
Support for multiple MCP clients and standalone usage:

- **Client Support**: Claude Desktop, Cursor IDE, Windsurf, other MCP-compatible clients

## Evolution from Basic Memory MCP

Advanced Memory MCP represents the next generation of the Basic Memory MCP foundation:

- **Expanded Research**: Multi-source intelligence vs. single-source notes
- **Enhanced Reliability**: Bulletproof sync and error handling vs. basic operations
- **Web Interface**: Standalone usage vs. MCP-client-only operation
- **Enterprise Features**: Production-grade testing and documentation vs. prototype implementation
- **Cross-Platform**: Universal compatibility vs. limited client support

The evolution maintains backward compatibility while significantly expanding capabilities and reliability for production research workflows.
