## 🎯 Common Tasks

### Daily Use
1. **Creating notes**: Ask Claude to create notes during conversations
2. **Searching**: Find information across all your notes
3. **Organizing**: Use folders and tags to structure content
4. **Linking**: Connect related ideas with wikilinks

### Weekly Maintenance
1. **Review new notes**: Check what Claude created
2. **Refine connections**: Add more wikilinks between related notes
3. **Update old notes**: Keep information current
4. **Export backups**: Save your knowledge base

## 💡 Best Practices

### Note Creation
- **One idea per note**: Keep notes focused
- **Descriptive titles**: Make notes easy to find
- **Use wikilinks**: Connect related concepts
- **Add tags**: Categorize broadly

### Organization
- **Folders for structure**: Use folders for major categories
- **Tags for themes**: Use tags for cross-cutting themes
- **Links for relationships**: Use wikilinks to show connections
- **Regular review**: Revisit and refine regularly

### Knowledge Building
- **Start small**: Begin with topics you know well
- **Build gradually**: Add notes over time
- **Connect ideas**: Link new notes to existing ones
- **Iterate**: Refine and expand as you learn
