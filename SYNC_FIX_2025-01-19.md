# Sync Fix - File Type Filtering Enhancement

**Date**: January 19, 2025  
**Issue**: User reported sync not working - showing zero notes despite having markdown files in folder

## Root Cause Analysis

The initial investigation revealed a misunderstanding of the requirements. The original code was designed to index **all file types**, not just markdown files. This supports use cases like:
- Code repositories (indexing source files, configs, etc.)
- Mixed-content knowledge bases
- Documentation projects

The user's actual need was for **configurable file type filtering** - the ability to choose between:
1. **All readable files** (default) - for code repos and mixed content
2. **Markdown only** - for pure note-taking

## Solution Implemented

### 1. Added Configuration Option

Added new `index_all_files` configuration parameter to `AdvancedMemoryConfig`:

```python
index_all_files: bool = Field(
    default=True,
    description="Whether to index all file types or only markdown (.md) files. "
                "Set to False to only index markdown files. default (True)",
)
```

**Files Modified:**
- `src/advanced_memory/config.py`
- `mcpb/src/advanced_memory/config.py`

### 2. Updated Sync Service

Modified `scan_directory()` to respect the `index_all_files` configuration:

```python
# If index_all_files is False, only index markdown files
if not self.app_config.index_all_files and not filename.endswith(".md"):
    logger.trace(f"Skipping non-markdown file (index_all_files=False): {filename}")
    continue
```

**Files Modified:**
- `src/advanced_memory/sync/sync_service.py`
- `mcpb/src/advanced_memory/sync/sync_service.py`

### 3. Enhanced Diagnostic Logging

Added better logging to help debug sync issues:
- Logs which folders are being skipped and why
- Warns when no files are found
- Traces file filtering decisions

### 4. Created Diagnostic Tool

Created `scripts/diagnose_sync.py` to help users debug sync issues:
- Shows what files will be indexed
- Identifies skipped folders
- Explains why files/folders are being ignored

### 5. Documentation

Created comprehensive documentation in `docs/user-guide/file-type-filtering.md` covering:
- How to configure file type filtering
- Use case examples
- Troubleshooting guide
- Migration instructions

## Behavior

### Default Mode (`index_all_files: true`)

Indexes **all file types** except:
- Hidden files (starting with `.`)
- Files in ignored folders (`node_modules`, `dist`, `build`, `__pycache__`, `.vscode`, etc.)
- Ignored file names (`.DS_Store`, `Thumbs.db`)

**Use cases:**
- Code repositories
- Mixed content projects
- Technical documentation
- Comprehensive knowledge bases

### Markdown-Only Mode (`index_all_files: false`)

Indexes **only `.md` files**, still respecting the ignore rules above.

**Use cases:**
- Pure note-taking
- Writing projects
- Markdown-focused workflows
- Smaller, focused knowledge bases

## Configuration Methods

### 1. Configuration File

Edit `~/.advanced-memory/config.json`:
```json
{
  "index_all_files": false
}
```

### 2. Environment Variable

```bash
export ADVANCED_MEMORY_INDEX_ALL_FILES=false
```

### 3. Claude Desktop MCP Config

```json
{
  "mcpServers": {
    "advanced-memory": {
      "env": {
        "ADVANCED_MEMORY_INDEX_ALL_FILES": "false"
      }
    }
  }
}
```
