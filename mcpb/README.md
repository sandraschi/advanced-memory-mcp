# MCPB Package Directory

This directory contains all files related to building and distributing Basic Memory as an MCPB (Model Context Protocol Binary) package for Claude Desktop.

## Contents

### 📦 Built Package
- **`advanced-memory-mcp.mcpb`** - The compiled MCPB package ready for distribution
  - This is the binary package that users can install in Claude Desktop
  - Generated by the build process from the source code

### ⚙️ Configuration Files
- **`mcpb.json`** - MCPB package configuration
  - Defines package metadata, entry points, and dependencies
  - Used during the build process to generate the MCPB package
  
- **`manifest.json`** - Package manifest
  - Contains detailed package information
  - Defines MCP server capabilities and resources
  
- **`requirements.txt`** - Python dependencies for the MCPB package
  - Specifies exact versions of Python packages needed
  - Bundled with the MCPB package for isolated installation

### 📖 Documentation
- **`MCPB_BUILDING_GUIDE.md`** - Comprehensive guide to building MCPB packages
  - Step-by-step build instructions
  - Troubleshooting and best practices
  - Distribution guidelines

### 📂 Source Code
- **`src/advanced_memory/`** - Copy of the source code for building
  - This is a snapshot of the main source used for the MCPB build
  - Contains all modules: MCP server, API, CLI, services, etc.
  
- **`data/`** - Static data and resources for the package

## Building the MCPB Package

### Quick Build
```bash
# From project root
python -m mcpb build mcpb/mcpb.json
```

### Build with Custom Output
```bash
python -m mcpb build mcpb/mcpb.json -o mcpb/advanced-memory-mcp.mcpb
```

See `MCPB_BUILDING_GUIDE.md` for detailed instructions.

## Installing the MCPB Package

### In Claude Desktop
1. Open Claude Desktop Settings
2. Navigate to Developer > Model Context Protocol
3. Click "Install from MCPB"
4. Select `advanced-memory-mcp.mcpb` from this directory

### Via Command Line
```bash
claude-mcp install mcpb/advanced-memory-mcp.mcpb
```

## Package Structure

The MCPB package includes:
- **MCP Server**: Full Model Context Protocol server implementation
- **Python Dependencies**: All required packages bundled
- **Database Schema**: SQLite schema and migrations
- **Static Resources**: Templates, prompts, and documentation
- **Configuration**: Default settings and project templates

## Distribution

The built MCPB package can be distributed through:
- **Direct Download**: Share the `.mcpb` file directly
- **GitHub Releases**: Attached to version releases
- **Package Registries**: Published to MCP package repositories
- **Documentation**: Linked from README and installation guides

## Development Notes

- The `src/` directory in this folder is a build artifact, not the primary source
- Primary source code is in the project's `src/` directory at the root
- Keep `mcpb.json` and `requirements.txt` in sync with project dependencies
- Rebuild the MCPB package after significant changes
- Test the package in a clean Claude Desktop environment before distribution

## Version Management

- MCPB package version is derived from git tags via `uv-dynamic-versioning`
- Package version should match the project version in `pyproject.toml`
- Update `manifest.json` when adding new MCP capabilities

## Troubleshooting

### Build Failures
- Ensure all dependencies are installed: `uv sync`
- Check that `mcpb.json` syntax is valid
- Verify Python version compatibility (3.12+)

### Installation Issues
- Ensure Claude Desktop is updated to latest version
- Check that MCPB package isn't corrupted (verify file size)
- Try installing in a fresh Claude Desktop profile

### Runtime Errors
- Check Claude Desktop logs for error messages
- Verify database permissions and paths
- Ensure all required dependencies are bundled
