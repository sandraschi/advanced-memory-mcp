# Academic Writing

Academic writing communicates research clearly, precisely, and persuasively.

## Core Characteristics

### 1. Clear and Precise
Every word serves a purpose.

```
❌ Vague: "The results were quite interesting and somewhat surprising."
✅ Clear: "Response time decreased 40% (p < 0.01), contrary to our hypothesis."
```

### 2. Evidence-Based
Claims supported by data and citations.

```
❌ Unsupported: "Everyone knows social media is harmful."
✅ Supported: "Recent studies show correlation between social media use and anxiety (Smith, 2023; Jones, 2024)."
```

### 3. Objective Tone
Focus on evidence, not personal opinion.

```
❌ Subjective: "I think this approach is obviously better."
✅ Objective: "This approach showed 30% improvement in three trials."
```

### 4. Structured
Logical organization guides reader.

## Paper Structure

### IMRaD Format

#### Introduction
- Background and context
- Research question/hypothesis
- Why it matters
- Brief overview of approach

#### Methods
- Study design
- Participants/materials
- Procedures
- Analysis approach

**Goal**: Another researcher could replicate your study.

#### Results
- Present findings objectively
- Use tables, figures, statistics
- No interpretation yet

#### Discussion
- Interpret results
- Compare to existing research
- Acknowledge limitations
- Suggest future research

## Writing Process

### 1. Planning (25% of time)
- Outline main arguments
- Organize evidence
- Plan structure

### 2. Drafting (35% of time)
- Write without editing
- Get ideas down
- Don't worry about perfection

### 3. Revising (40% of time)
- Strengthen arguments
- Improve clarity
- Check logic
- Verify citations

## Paragraphs

### Structure
1. **Topic Sentence**: Main idea
2. **Supporting Sentences**: Evidence and explanation
3. **Concluding Sentence**: Transition to next idea

### Example
```
Topic: The Zettelkasten method improves learning outcomes.

Supporting: Studies show active note-taking enhances retention (Mueller & Oppenheimer, 2014).
The method's emphasis on reformulation and linking strengthens understanding.

Concluding: These benefits make Zettelkasten particularly effective for complex subjects.
```

## Citations

### In-Text Citations

**APA Style**:
```
Smith (2023) found that...
Recent research shows... (Smith, 2023; Jones, 2024).
```

**MLA Style**:
```
Smith argues that... (45).
Recent research shows... (Smith 45; Jones 78).
```

### Reference List

**APA**:
```
Smith, J. (2023). Title of article. Journal Name, 12(3), 45-67.
https://doi.org/10.1234/example
```

**MLA**:
```
Smith, John. "Title of Article." Journal Name, vol. 12, no. 3, 2023, pp. 45-67.
```

## Common Mistakes

### 1. Passive Voice Overuse
```
❌ "The experiment was conducted by the researchers."
✅ "We conducted the experiment." (Active, clearer)
```

### 2. Unnecessary Jargon
```
❌ "Utilize methodological approaches to operationalize constructs."
✅ "Use methods to measure concepts."
```

### 3. Weak Transitions
```
❌ "Also, another thing is..."
✅ "Furthermore, this finding suggests..."
✅ "In contrast to previous research..."
✅ "Building on this foundation..."
```

### 4. Unclear Pronouns
```
❌ "The study examined teachers and students. They showed improvement."
   (Who? Teachers or students?)
✅ "The study examined teachers and students. Students showed improvement."
```

## Revision Checklist

### Content
- [ ] Clear thesis/research question
- [ ] Logical organization
- [ ] Sufficient evidence
- [ ] Addresses counterarguments
- [ ] Acknowledges limitations

### Clarity
- [ ] Each paragraph has clear focus
- [ ] Transitions connect ideas
- [ ] Technical terms defined
- [ ] Examples illustrate points

### Style
- [ ] Appropriate tone
- [ ] Active voice (mostly)
- [ ] Varied sentence structure
- [ ] No unnecessary words

### Mechanics
- [ ] Grammar and spelling correct
- [ ] Citations properly formatted
- [ ] Figures/tables labeled
- [ ] References complete

## Getting Feedback

### Peer Review
- Exchange drafts with colleagues
- Specific questions guide feedback
- Multiple rounds improve quality

### Writing Centers
- Professional feedback
- Learn writing strategies
- Develop skills

### Self-Review
- Read aloud (catches awkward phrasing)
- Wait 24 hours before revising
- Print and mark up physically
