# Effective Learning Strategies

Evidence-based techniques for learning more effectively.

## Proven Strategies

### 1. Spaced Repetition
Review material at increasing intervals.

**Why It Works**: Strengthens memory through retrieval practice.

**Implementation**:
```
Day 1: Learn new concept
Day 2: Review
Day 4: Review
Day 7: Review
Day 14: Review
Day 30: Review
```

**Tools**:
- Anki (flashcards)
- SuperMemo
- Built into Advanced Memory

### 2. Active Recall
Test yourself instead of re-reading.

**Techniques**:
- Flashcards
- Practice problems
- Explaining to others
- Writing summaries from memory

**Why It Works**: Retrieval strengthens memory more than passive review.

### 3. Elaboration
Connect new information to existing knowledge.

**Questions to Ask**:
- How does this relate to what I already know?
- What are examples of this concept?
- Why does this work this way?
- How could I explain this to someone else?

### 4. Interleaving
Mix different topics/skills in study sessions.

```
❌ Blocked Practice:
  Monday: Topic A, A, A, A
  Tuesday: Topic B, B, B, B

✅ Interleaved Practice:
  Monday: Topic A, B, C, A, B, C
  Tuesday: Topic B, C, A, C, A, B
```

**Why It Works**: Forces discrimination between concepts, strengthens understanding.

### 5. Concrete Examples
Use specific examples to understand abstract concepts.

**Abstract**: "Recursion is when a function calls itself."

**Concrete**:
```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)  # Function calls itself

# factorial(5) = 5 * factorial(4) = 5 * 4 * 3 * 2 * 1 = 120
```

### 6. Dual Coding
Combine words and visuals.

**Techniques**:
- Draw diagrams while reading
- Create concept maps
- Use visual metaphors
- Sketch processes

## Learning Cycle

### 1. Preparation
- Preview material
- Activate prior knowledge
- Set specific goals

### 2. Engagement
- Active reading/watching
- Take notes
- Ask questions
- Try examples

### 3. Consolidation
- Summarize in own words
- Create connections
- Test understanding
- Identify gaps

### 4. Practice
- Apply knowledge
- Solve problems
- Create projects
- Teach others

### 5. Reflection
- What did I learn?
- What's still unclear?
- How does this connect?
- What's next?

## Ineffective Strategies

### ❌ Passive Re-reading
Reading same material repeatedly without testing.

**Why Ineffective**: Creates illusion of knowledge without deep understanding.

### ❌ Highlighting
Marking text without processing.

**Why Ineffective**: Passive activity, doesn't engage with material.

### ❌ Cramming
Massed practice right before test.

**Why Ineffective**: Poor long-term retention, high stress.

### ❌ Multitasking
Studying while distracted.

**Why Ineffective**: Divided attention prevents deep processing.

## Study Techniques

### Pomodoro Technique
25 minutes focused work, 5 minute break.

```
🍅 25 min: Deep focus on one topic
☕ 5 min: Break (walk, stretch)
🍅 25 min: Continue or switch topics
☕ 5 min: Break
🍅 25 min: Study session
☕ 15 min: Longer break
```

### Feynman Technique
1. Choose concept
2. Explain it simply (as if to a child)
3. Identify gaps in explanation
4. Review and simplify further

### SQ3R Method
1. **Survey**: Skim material
2. **Question**: Turn headings into questions
3. **Read**: Read actively
4. **Recite**: Summarize in own words
5. **Review**: Test understanding

## Metacognition

### Monitor Understanding
- Can I explain this without notes?
- Can I apply this to new situations?
- What don't I understand yet?

### Adjust Strategies
- If not working, try different approach
- Match strategy to material type
- Experiment and reflect

## Creating Effective Study Environment

### Physical Space
- Quiet, comfortable location
- Good lighting
- Minimal distractions
- All materials ready

### Digital Environment
- Close unnecessary tabs
- Turn off notifications
- Use website blockers if needed
- Have reference materials ready

### Mental State
- Well-rested
- Hydrated
- Specific goals
- Positive mindset
