# Character Development

Creating complex, believable characters that readers care about.

## Core Elements

### Want vs. Need

**Want**: What character thinks they need
**Need**: What they actually need to be fulfilled

```
Example (Breaking Bad):
Want: Walter White wants to provide for his family
Need: Walter needs to feel powerful and important
```

The gap between want and need creates internal conflict.

### Backstory

Character's history shapes their present.

**Include**:
- Formative experiences
- Relationships
- Traumas
- Victories
- Values formed

**But**: Only reveal what serves the story.

### Motivation

Why does character act?

**Strong motivations**:
- Survival
- Love/protection of others
- Justice
- Redemption
- Ambition
- Revenge

**Weak motivations**:
- "Because plot requires it"
- Unclear desires
- Inconsistent goals

## Character Arc

### Positive Arc
Character overcomes flaw and achieves need.

```
1. Start: Flawed but sympathetic
2. Inciting incident: Want established
3. Struggles: Want vs. Need conflict
4. Crisis: Must choose
5. Climax: Embraces need, transforms
6. Resolution: New person
```

**Example**: Ebenezer Scrooge transforms from miser to generous.

### Negative Arc
Character fails to overcome flaw, descends.

```
1. Start: Flawed
2. Choices driven by flaw
3. Consequences worsen
4. Crisis: Final choice
5. Climax: Embraces flaw
6. Resolution: Tragic end
```

**Example**: Walter White becomes the villain.

### Flat Arc
Character already has truth, changes world instead.

```
1. Start: Character knows truth
2. World opposes truth
3. Character tested but stays true
4. Character's truth transforms others
```

**Example**: Captain America maintains values, inspires others.

## Creating Distinct Characters

### Unique Voice
Each character should sound different.

```
Teenager: "Whatever. Like I even care."
Professor: "I must respectfully disagree with that assessment."
Hardened cop: "Cut the BS. Where were you last night?"
```

### Contrasting Traits
Avoid all-good or all-bad.

```
❌ Flat: "Hero is brave, kind, honest, strong, and smart."
✅ Rounded: "Hero is brave but reckless, kind but naive,
strong but prideful."
```

### Flaws That Matter
Flaws should create problems, not be cute quirks.

```
❌ Cute: "She's clumsy! How adorable!"
✅ Meaningful: "Her inability to trust anyone keeps her isolated
and prevents the relationships she desperately needs."
```

## Revealing Character

### Through Action
```
❌ "John was brave."
✅ John ran toward the burning building while others fled.
```

### Through Dialogue
What they say and how they say it.

### Through Reaction
How they respond to stress reveals truth.

### Through Relationships
How they treat others, especially those with less power.

### Through Choice
The decisions they make under pressure.

### Through Internal Thought
(In POV character) What they think but don't say.

## Supporting Characters

### Function
Each should have a role:
- **Ally**: Supports protagonist
- **Antagonist**: Opposes protagonist
- **Mentor**: Teaches protagonist
- **Love interest**: Complicates protagonist
- **Foil**: Highlights protagonist through contrast

### Avoid Stereotypes
Give even minor characters specificity.

```
❌ "The elderly shopkeeper"
✅ "Mrs. Chen, who'd run the corner store for forty years and
knew every customer's coffee order"
```

## Character Consistency

### Internal Logic
Character should act according to their established nature.

```
If character is established as cautious, they shouldn't suddenly
take reckless risks without good reason.
```

### Growth is Not Inconsistency
Characters can change, but change needs cause.

```
❌ Inconsistent: Shy character suddenly becomes confident (no reason)
✅ Growth: Shy character gains confidence through series of small
victories and encouragement from mentor
```

## Common Mistakes

### Mary Sue/Gary Stu
Character who's perfect, loved by all, no real flaws.

**Fix**: Add meaningful flaws, have character earn victories.

### Unearned Change
Character suddenly transforms without sufficient cause.

**Fix**: Show gradual change through experiences.

### All Tell, No Show
Describing character instead of demonstrating through action.

**Fix**: Replace descriptions with revealing scenes.

### Talking Head
Character exists only to deliver information.

**Fix**: Give them their own goals, personality, conflicts.

## Practice Exercises

1. **Interview Your Character**: Answer questions in character's voice
2. **Write Backstory Scene**: Important moment that shaped them
3. **Place in Conflict**: How do they react under pressure?
4. **Meet Another Character**: How do they interact?
